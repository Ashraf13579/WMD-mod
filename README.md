# WMD: Weapons of Mass Destruction

A modern-military mod for **NeoForge 1.21.1**: missiles you build from four parts (airframe, motor, guidance, warhead), radar and air
defence, artillery, drones, satellites and orbital strikes, a full industry to build it all, and explosions that leave their mark on the world.

Download the mod from its CurseForge page. This repository holds the source of each weekly release.

## Building
Requirements: JDK 21.

```
./gradlew build
```

The jar is written to `build/libs/`. Required at runtime: NeoForge 21.1.200 or newer and GeckoLib 4.8 or newer. Optional integrations:
Distant Horizons, Veil, Sable, Create (6.0.10+), Create: Deep Seas (3.3.0+), JEI / EMI, Jade, CC: Tweaked, BlueMap.
